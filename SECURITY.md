# Security policy

Narraiva DSH is an alpha release. Please do not use public issues for API keys, unpublished manuscripts, path disclosures, or exploitable security details.

Report a vulnerability through the repository’s GitHub private security advisory feature. Include affected version, operating system, DSH version, reproduction steps, impact, and a minimal redacted project when possible. The maintainers will acknowledge a complete report as capacity permits; this volunteer project does not promise a fixed response SLA.

Supported security updates currently target the latest `0.1.0-alpha.x` release only. Never include a DeepSeek API key in a report. Rotate any credential that may have been exposed.
