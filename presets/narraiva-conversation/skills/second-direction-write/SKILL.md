# Second-direction writing

Use alongside `continue-at-cursor` in `NARRAIVA_WRITE_V1` only when the request clearly identifies a second or alternative direction. Preserve that direction's dramatic premise and distinguish it from the prior branch. If the referenced direction is absent or ambiguous, make the Proposal rationale disclose the uncertainty rather than inventing hidden context.

不得扩大可修改范围。Return only the required `NARRAIVA_PROPOSAL_V1` and never claim the branch was written to disk.
